# Florify 🌷

AI-ассистент приёма заказов для цветочного магазина — кликабельный прототип без бэкенда: вся логика и данные живут в памяти браузера (React-подобный стейт на чистом JS), при обновлении страницы сбрасываются в демо-набор.

Собран для демонстрации на защите курса.

## Экраны

- **Заказы** — вставьте сообщение клиента в поле сверху и нажмите «Распознать ИИ»: эвристический парсер на JS вытащит состав букета, бюджет, дату/время доставки, адрес, имя клиента и канал (WhatsApp/Instagram). Поля можно поправить руками перед созданием заказа. Ниже — канбан-доска (Новый → В сборке → Передан курьеру → Доставлен) с перетаскиванием карточек между колонками.
- **Клиенты** — таблица клиентов с количеством заказов, форма добавления нового клиента.
- **Склад** — остатки цветов, +/− для изменения количества, бейдж «мало» при остатке < 10 шт.
- **Списания** — форма списания (цветок, количество, причина), история списаний; при добавлении автоматически уменьшает остаток на складе.
- **Сводка** — 4 метрики, посчитанные из текущего состояния: заказов сегодня, выручка за неделю, списано за месяц, позиций с низким остатком.

## Технологии

Один самодостаточный HTML-файл: чистый JavaScript (без фреймворков и сборки), CSS-переменные для темы, шрифты Manrope + Golos Text из Google Fonts. Внешних зависимостей и бэкенда нет.

## Запуск локально

Файл полностью статический, вариантов запуска два:

**Просто открыть в браузере**

Дважды кликнуть на `index.html`.

**Через локальный сервер** (удобнее, если браузер капризничает с `file://`)

```bash
python -m http.server 5173
# затем открыть http://localhost:5173/
```

или

```bash
npx http-server -p 5173
```

## Примечание

Это прототип «выглядит и работает»: данные хранятся только в памяти вкладки, реального ИИ и базы данных нет — распознавание переписки эмулируется эвристическим парсером с искусственной задержкой.
